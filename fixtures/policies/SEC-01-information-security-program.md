# SEC-01 Information Security Program

## Program

1.1 Halcyon Ridge Software maintains a written information security program approved by the Chief Technology Officer and reviewed at least annually.

1.2 The Security Engineering Lead owns the program and reports security risks to company leadership every quarter.

1.3 All security policies are published internally and acknowledged by every workforce member at hire and annually.

## Exceptions and assurance

1.4 Exceptions to a security policy require a documented risk acceptance approved by the Security Engineering Lead and expire after at most 12 months.

1.5 The program is designed around common industry control frameworks. Halcyon Ridge Software does not currently hold a third-party security certification or attestation report.
