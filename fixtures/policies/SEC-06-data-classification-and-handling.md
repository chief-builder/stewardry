# SEC-06 Data Classification and Handling

## Classification

6.1 Data is classified as Public, Internal, Confidential, or Customer Restricted.

6.2 Customer data is classified as Customer Restricted and is stored only in production environments.

## Handling

6.3 Customer Restricted data must not be copied to developer workstations or to non-production environments.

6.4 Test data is synthetic or irreversibly anonymized.

6.5 Removable media may not be used for Customer Restricted data.
