# SEC-19 Physical Security

## Offices

19.1 Halcyon Ridge Software offices use badge access, and visitors are escorted at all times.

19.2 Production systems are hosted entirely with the cloud provider. Halcyon Ridge Software offices contain no production systems.

## Data centers

19.3 Physical security of data centers is the cloud provider's responsibility, and the provider's controls are reviewed every year.
